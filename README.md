# CodSoft Java Development Internship

Hi! 👋

Welcome to my repository. This is where I've added the Java projects I worked on as part of my **CodSoft Java Development Internship**.

I created these projects to improve my Java programming skills, practice problem-solving, and understand how Java concepts can be used to build simple applications.

## 📌 Projects

### 1. Number Guessing Game

This is a simple game where the computer generates a random number between 1 and 100, and the player has to guess it.

**What it does:**
- Tells the player whether the guess is too high or too low.
- Gives a limited number of attempts.
- Allows the player to play multiple rounds.
- Keeps track of the rounds won and guesses made.

### 2. Student Grade Calculator

This program helps calculate a student's total marks, average percentage, and grade based on the marks entered for each subject.

**What it does:**
- Takes marks for multiple subjects.
- Calculates the total and average percentage.
- Assigns a grade based on the average.
- Displays the final result.

### 3. ATM Interface

I built this program to simulate some basic operations that we usually find in an ATM.

**What it does:**
- Checks the account balance.
- Deposits money into the account.
- Withdraws money from the account.
- Checks transaction amounts and prevents withdrawals when the balance is insufficient.

### 4. Quiz Application

This is a quiz application built using Java Swing. It displays multiple-choice questions and gives the user a limited time to answer each question.

**What it does:**
- Displays questions with multiple options.
- Includes a timer for each question.
- Calculates the score.
- Shows the final result and a summary of answers.

### 5. Student Course Registration System

This project simulates a basic course registration system where students can view available courses and manage their registrations.

**What it does:**
- Displays the available courses.
- Allows students to register for courses.
- Checks course capacity and duplicate registrations.
- Allows students to drop a course.
- Shows the courses registered by a student.

## 🛠️ Technologies Used

## ▶️ How to Run

1. Clone or download this repository.
2. Open Eclipse IDE.
3. Import the project into Eclipse. If a `pom.xml` file is included, import it as an existing Maven project.
4. Open `src/main/java` and find the task you want to run.
5. Open the corresponding Java class.
6. Right-click the class and select **Run As → Java Application**.
7. Follow the instructions shown in the application.
